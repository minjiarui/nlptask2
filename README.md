# nlptask2
NLP Project Collab with Jonny 

## Setup
1. Install PyTorch for your machine (CUDA build from https://pytorch.org on GPU machines), then:
   ```
   pip install -r requirements.txt
   ```
2. Download `XNLI-1.0.zip` and `XNLI-MT-1.0.zip` and extract them into this folder (they are gitignored):
   ```
   XNLI-1.0/
   XNLI-MT-1.0/
   ```
3. Open `default_final_project.ipynb` and run the cells top to bottom.
